Privacy Policy — FRACS Study

Effective 1 October 2026 · Applies to the FRACS Study application and its use of Google APIs

FRACS Study ("the application") is a private, single-user study tool operated by David Zula. This policy explains what information the application accesses, why, where it is stored, and how it is protected. The application is used by one person only — the owner of the Google Account that authorises it.

Limited Use disclosure. FRACS Study's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

1. Google user data the application accesses

The application requests the following Google API scopes, and uses them only as described:

Google serviceWhat is accessedWhy
Google Drive Create and upload files, and read file metadata, within the authorising user's own Drive To save generated study documents into a folder in the user's own Drive
Gmail (read-only) Message metadata and content of the user's own mailbox To surface study-related correspondence to the user on request
Gmail (send / modify) Ability to send messages and apply labels as directed by the user To send or file messages only when the user explicitly instructs it
Google Calendar Events on the user's own calendars To read and display the user's study schedule
Google Sheets & Google Docs Documents and spreadsheets owned by, or shared with, the user To read study data the user points the application at, and to create documents where asked
Google Contacts (read-only) The user's own contact list To resolve names to addresses for the user's own correspondence

2. How the data is used

  • Data is used solely to operate the application for its single user — producing study documents and placing them in the user's own Drive.
  • The application does not use Google user data for advertising, profiling, creditworthiness, or any lending decision.
  • The application does not use Google user data to train, tune or improve any artificial-intelligence or machine-learning model, and does not transfer it for that purpose.
  • No human other than the user reads the data. There are no other users, staff, or contractors.
  • Automated processing (summarising reference material and formatting documents) happens on the user's own computer.

3. Sharing and transfer

  • Google user data is not sold, rented, traded or transferred to any third party.
  • It is not shared with advertising platforms, data brokers, or information resellers.
  • The only recipient of the documents produced is the user's own Google Drive.
  • Where the application sends reference material to a language-model or search provider to draft a summary, that material is public reference text (for example public medical guidelines) obtained separately — Google user data is not included in those requests.

4. Storage, security and retention

  • Generated documents are stored on the user's own computer and in the user's own Google Drive. No additional copy is kept anywhere else.
  • Google authorisation is held as an OAuth refresh token on the user's own encrypted, password-protected computer, in a file readable only by the user's account.
  • Access tokens are short-lived and renewed automatically; the authorisation can be revoked at any time via the user's Google Account permissions page.
  • Data is retained only while it remains useful for the user's study. The user may delete any document directly from their own Drive at any time.

5. Deletion and revocation

  • Revoke the application's access at myaccount.google.com/permissions; access ceases immediately.
  • Documents can be deleted from Google Drive by the user at any time, which removes them permanently in the ordinary way.
  • To request deletion of anything held locally, contact the address below.

6. Children

The application is not directed to children and is not offered to any user other than its owner.

7. Changes to this policy

Any revision will be published on this page with an updated effective date.
